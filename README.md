# MenuReader

在Mac菜单栏上偷偷看小说的小工具。

## 功能

- 📖 菜单栏直接显示小说文字
- ⏩ 自动翻页（可调节速度）
- 📁 支持导入TXT文件
- 💾 自动记住上次打开的文件

## 系统要求

- macOS 13.0 (Ventura) 或更高版本
- Xcode Command Line Tools

## 安装

1. 克隆或下载项目
2. 运行构建脚本：

```bash
chmod +x build.sh
./build.sh
```

3. 运行生成的可执行文件：

```bash
./build/MenuReader
```

## 使用

1. 启动后，菜单栏会显示"📖 点击导入小说"
2. 点击菜单栏图标，选择"导入TXT文件"
3. 选择一个TXT文件
4. 菜单栏会自动显示小说内容
5. 默认每10秒自动翻页，可在菜单中调整速度

## 快捷操作

- **播放/暂停**：点击菜单栏图标中的播放/暂停按钮
- **上一页/下一页**：点击前进/后退按钮
- **调整速度**：选择5秒、10秒、30秒或60秒间隔

## 注意事项

- 每页显示约20个字符（菜单栏空间有限）
- 应用会在菜单栏常驻，退出需点击菜单中的"退出"
- 支持中文、英文等UTF-8编码的TXT文件
