# MenuReader 功能文档

## 项目简介

MenuReader 是一款 macOS 菜单栏小说阅读器。它将文本内容以分页形式显示在菜单栏或屏幕顶部居中位置，支持自动翻页、全局快捷键操控，适合在工作间隙"摸鱼"阅读。

- 平台要求：macOS 13.0+
- 技术栈：Swift + SwiftUI + AppKit, Swift Package Manager 构建
- 依赖：[KeyboardShortcuts](https://github.com/sindresorhus/KeyboardShortcuts)

## 功能列表

### 阅读核心

- 加载 UTF-8 纯文本文件（`.txt`）
- 自动分页，支持智能断句（优先在标点处断页）
- 禁首标点处理（不会让标点出现在下一页开头）
- 阅读进度自动保存（基于字符偏移量，换页字数不丢进度）

### 显示模式

| 模式 | 说明 |
|------|------|
| 右侧（right） | 文本直接显示在菜单栏状态图标位置，使用等宽字体，固定宽度防跳动 |
| 居中（center） | 文本显示在屏幕顶部正中的透明浮窗中，不遮挡操作，适配刘海屏 |

- 隐藏时菜单栏显示书籍图标，不显示文本
- 居中模式使用 NSPanel overlay，所有桌面空间可见

### 分页控制

- 手动翻页（上一页 / 下一页）
- 自动播放 / 暂停
- 翻页间隔可调：0.1s ~ 1.0s（10 档）
- 每页字数可调：10 / 20 / 30 / 40 / 50 / 60 字

### 书库管理

- 支持添加多本书籍（多选文件）
- 自动去重（相同路径不重复添加）
- 切换书籍时显示书名 1.5 秒
- 删除书籍
- 循环切换上/下一本

### 全局快捷键

所有快捷键可在设置中自定义修改。默认值：

| 功能 | 默认快捷键 |
|------|-----------|
| 隐藏/显示 | `Ctrl+Option+O` |
| 暂停/继续 | `Ctrl+Option+P` |
| 上一页 | `Ctrl+Option+H` |
| 下一页 | `Ctrl+Option+L` |
| 上一本书 | `Ctrl+Option+K` |
| 下一本书 | `Ctrl+Option+J` |
| 切换显示位置 | `Ctrl+Option+;` |

快捷键设计参考 Vim 方向键（H/J/K/L）。

### 设置窗口

设置窗口包含三个标签页（toolbar 样式切换）：

**通用**
- 开机自启动（SMAppService）
- 显示位置（右侧 / 居中）
- 每页字数
- 翻页间隔

**书库**
- 书籍列表（显示当前页码/总页数）
- 当前选中书籍标记
- 添加 / 删除书籍

**快捷键**
- 所有快捷键的录制和修改

### 菜单操作

点击菜单栏图标弹出菜单：

- 显示 / 隐藏
- 播放 / 暂停
- 上一页 / 下一页
- 显示位置子菜单（右侧 / 居中）
- 每页字数子菜单
- 翻页间隔子菜单
- 书籍选择子菜单
- 设置
- 退出

## 使用方法

1. 启动后在菜单栏右侧出现书籍图标
2. 点击图标 → 菜单 → 设置 → 书库 → 添加书籍
3. 添加 .txt 文件后自动开始显示第一页
4. 使用快捷键 `Ctrl+Option+P` 开始自动翻页
5. 使用 `Ctrl+Option+O` 快速隐藏/显示（老板键）
6. 使用 `Ctrl+Option+;` 在右侧和居中模式间切换

## 数据存储

- 书库信息：UserDefaults（JSON 编码）
- 阅读进度：以字符偏移量（characterOffset）存储，修改每页字数后不丢失进度
- 设置项：UserDefaults（displayMode, pageSize）
